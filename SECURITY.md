# Security policy

This policy covers every repository in the [vexotech](https://github.com/vexotech) organization, including the Vexo server SDKs.

## Report a vulnerability

Don't open a public issue for a security vulnerability. Report it privately instead:

- On GitHub, open the repository's **Security** tab and select **Report a vulnerability**.
- Or email [hello@vexo.co](mailto:hello@vexo.co) with "Security" in the subject.

Include the affected repository and version, the steps to reproduce the issue, and the impact you expect. We'll confirm we received your report and keep you updated until it's fixed.

## Supported versions

Security fixes go into the latest release of each SDK. To get a fix, upgrade to the latest version.
