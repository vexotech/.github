# Contributing

Thanks for helping improve Vexo's open-source projects.

- To report a bug or request a feature, open an issue in the project's repository. For a security issue, follow the [security policy](SECURITY.md) instead.
- Before you open a pull request for a larger change, open an issue so we can agree on the approach.
- Keep each pull request focused, add tests for any behavior you change, and make sure the project's tests pass.
- The server SDKs share one behavior contract. If you change how an SDK sends events, check the change against [vexo-sdk-conformance](https://github.com/vexotech/vexo-sdk-conformance).

By contributing, you agree that your contribution is licensed under the project's license.
