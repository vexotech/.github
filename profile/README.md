# Vexo Analytics

Product analytics and session replay for React Native, Expo, and web apps.

One SDK call records session replays, tap heatmaps, funnels and retention, crashes, app performance, and network requests, so you can see what a user did before a bug and where users drop off.

## Get started

- **Website:** [vexo.co](https://www.vexo.co)
- **Docs:** [docs.vexo.co](https://docs.vexo.co)
- **React Native and Expo SDK:** [`vexo-analytics` on npm](https://www.npmjs.com/package/vexo-analytics)
- **Live demo:** [see the dashboard with sample data](https://www.vexo.co/apps/demo-app-5251-5325-8544)

## Open-source tools

- **[vexo-mcp-plugin](https://github.com/vexotech/vexo-mcp-plugin):** query your Vexo analytics from Claude Code, Cursor, and Claude Desktop.
- **[vexo-go](https://github.com/vexotech/vexo-go):** send events from Go services. See [server-side capture](https://docs.vexo.co/server-side/capture) for the HTTP API.
